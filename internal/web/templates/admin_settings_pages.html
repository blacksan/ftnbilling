Router console

One plain RouterOS command, e.g. /ip address print where interface=ether1. No scripting: ; [ ] { } $ : are refused. Read-only commands (print, get, monitor ... once, export, ping, tool traceroute) run at once, secrets hidden. add, set, remove, enable, disable and reset-counters need the router name and your password. reboot and shutdown: use the router's Danger tab. Users, scripts, scheduler, services, certificates, WireGuard, files and secrets are never run. Every submission is logged with secrets masked, never the output.
