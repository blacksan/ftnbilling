Router console

One plain RouterOS command, such as /ip address print where interface=ether1. No scripting: ; [ ] { } $ : and quotes with those inside are refused. Read-only commands (print, get, monitor ... once, export, ping, tool traceroute) run at once; print always shows one line per item with secret values hidden. add, set, remove, enable, disable and reset-counters need the router name and your password. reboot and shutdown are refused here: use the Reboot button on the router's Danger tab. Users, scripts, the scheduler, services, certificates, WireGuard changes, files and secrets are never run. Every submission is logged (command with secrets masked, outcome, size; never the output).
