{{.Data.ConsoleScript}}

Why this is not automatic

A factory OLT answers only on 192.168.8.200 on its untagged port. Reaching it from the server would need the router to put an address of that network on the customer-facing OLT port, which would also expose the OLT to every customer on it. The paste above avoids that.
