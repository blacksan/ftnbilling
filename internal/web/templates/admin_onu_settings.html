Set up the OLT

Once per OLT profile. Each router also needs its management network (ONUs tab, or a new join line).

V-SOL

  1. Create a VLAN for management on the OLT (default {{.Data.Default}}) and allow it tagged on the uplink port that goes to the router.
  2. In the tenant ONU profile, add a WAN of mode TR-069 (internet type "TR069"), VLAN {{.Data.Default}}, DHCP, with the LAN binding the profile asks for.
  3. In the profile's TR-069 section set URL {{.Data.URL}}, the username and password above, and periodic inform on at {{.Data.Interval}} seconds.
  4. Apply the profile (or re-register the ONUs). They appear under ONUs within minutes.

ZTE

On the ONU template set a TR069 WAN on the management VLAN with DHCP, plus the ACS URL, username and password. Newer boxes also have a TR-069 page under Management.

Huawei

In the line or service profile add a TR069 WAN on the management VLAN with DHCP, and set the ACS URL, username and password (OMCI or the ONT web page). Some models take the URL only from DHCP option 43, which the router already sends.
