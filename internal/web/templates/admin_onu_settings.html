Set up the OLT

Do this once per OLT profile. Each router also needs its management network (the router's ONUs tab, or a new join line).

V-SOL

  1. Create a VLAN for management on the OLT (default {{.Data.Default}}) and allow it tagged on the uplink port that goes to the router.
  2. In the ONU profile used for tenants, add a service/WAN of mode TR-069 (internet type "TR069"), VLAN {{.Data.Default}}, DHCP, and turn on its binding to the LAN side as the profile asks.
  3. In the profile's TR-069 section set URL {{.Data.URL}}, the username and password above, and periodic inform on at {{.Data.Interval}} seconds.
  4. Apply the profile to the ONUs (or re-register them). Within a few minutes the ONU appears under ONUs.

ZTE

On the ONU template set the same WAN of type TR069 on the management VLAN with DHCP, and the ACS URL, username and password. Newer ZTE boxes also have a TR-069 page in their own web page under Management.

Huawei

In the ONT line or service profile add a TR069 WAN on the management VLAN, DHCP, and set the ACS URL, username and password on the ONT (OMCI or the device's web page). Some Huawei models only take the URL from DHCP option 43, which the router already sends.

Changing the password above breaks every ONU's login until its profile has the new one.
